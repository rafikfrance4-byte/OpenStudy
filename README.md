
# OpenStudy 📚

An open-source productivity toolkit for students.

## About

OpenStudy is a simple and free student productivity website designed to help students organize their academic tasks and manage their study time.

## Features

- Add and delete study tasks.
- Organize tasks by subject.
- Set task dates.
- Mark tasks as completed.
- Filter tasks by status.
- Save tasks automatically in the browser.
- Responsive design for mobile and desktop.

## Technologies

- HTML5
- CSS3
- JavaScript
- Local Storage

## How to use

1. Open the OpenStudy website.
2. Add a task.
3. Enter the subject and date.
4. Mark tasks as completed when you finish them.

## Run locally

Download or clone this repository and open `index.html` in your browser.
